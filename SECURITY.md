# Reporting a security issue

Please report security issues privately to **lex@gradient-ds.com**, with
"security" in the subject — not in a public issue.

Include what you found, how to reproduce it, and how you would like to be
credited. We aim to acknowledge a report within two working days and to keep
you updated until it is resolved. Please give us a reasonable chance to fix an
issue before disclosing it publicly.

This policy covers the repositories in this organisation. For the products we
run for customers, security contacts are in the contract with that customer.
